## 📋 概述

这是本项目的第 2 代迭代版本，基于 `1/` 迭代版的稳健性优化，进一步引入了**自动超参数调优**、**异常值处理**和**多重防止过拟合机制**。

本版本在性能、泛化能力以及运行鲁棒性方面都进行了提升。相比原始 baseline 和迭代 1，更适合用于稳定提交与结果对比。

## ✨ 核心特性

### 🎯 自动超参数调优
- **自我迭代优化**：使用随机搜索算法自动寻找最佳超参数组合
- **30次迭代调优**：在8维参数空间中进行高效探索
- **交叉验证保证**：3折GroupKFold确保调优结果的可靠性
- **实时反馈**：详细记录调优过程和最佳参数

### 🛡️ 防止过拟合机制
- **正则化**：XGBoost的L1/L2正则化 + RandomForest的CCP后剪枝
- **早停机制**：XGBoost自动早停防止过拟合
- **复杂度控制**：限制树深度、最小叶子权重等
- **过拟合检测**：自动计算训练/验证集性能比率并报警

### 🔍 异常值处理
- **IQR方法检测**：使用四分位距范围自动识别异常值
- **智能修复**：用中位数替换异常值，保持数据分布
- **全面覆盖**：处理数值特征和目标变量的异常值
- **详细日志**：记录每个特征的异常值处理情况

### 🧬 高级特征工程
- **颜色饱和度**：$\sqrt{a_0^2 + b_0^2}$ - 反映初始颜色的鲜艳度
- **时间对数变换**：$\log(1 + \text{aging\_time\_day})$ - 处理非线性时间关系
- **交互特征**：老化时间 × 颜色饱和度 - 捕捉协同效应
- **颜色复杂度**：$L_0 \times \sqrt{a_0^2 + b_0^2}$ - 综合亮度和色度
- **样品类别推理**：从样品名称自动提取颜料类别

### 🤖 智能模型选择
- **XGBoost优先**：梯度提升树，更好处理非线性关系
- **RandomForest备选**：若XGBoost不可用自动切换
- **调优后参数**：基于数据自动优化的超参数
- **Pipeline架构**：预处理 + 模型的完整机器学习管道

### 📊 鲁棒评估方法
- **GroupKFold**：5折分组交叉验证，避免数据泄露
- **多指标评估**：MAE、RMSE、R²综合评价
- **过拟合监控**：训练集vs验证集性能对比
- **详细报告**：每折性能和最终平均指标

## 算法原理

### 特征工程依据

1. **颜色饱和度**：Lab颜色空间中的色度（Chroma），是感知颜色差异的重要成分
2. **对数时间**：许多化学反应遵循对数衰减规律
3. **交互特征**：初始颜色越鲜艳的物质，老化速率可能不同
4. **样品类别**：不同材料的老化特性差异显著

### 模型选择理由

- **XGBoost**：通过迭代学习残差，更好地拟合复杂的非线性关系
- **GroupKFold**：尊重数据的聚簇结构（平行样），提供更可靠的泛化估计
